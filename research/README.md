# Historical experiments

These authored source tools are retained to preserve the investigation, not as a supported installation path. They include diagnostics, version-specific probes and abandoned experiments. They can change runtime files or use coordinates/offsets that belong to old versions.

Prefer the scripts at the repository root and the current tools described in `docs/`. Research templates use the same machine-path tokens; inspect and port a tool before running it. Logs, client binaries, game assets, account data, generated shader captures and backups are deliberately absent.
